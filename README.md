# Calculadora de Salario y Costos Laborales - Colombia 🇨🇴

Una herramienta web intuitiva y precisa para calcular el costo real de un empleado en Colombia, basada en la normativa del SMMLV - Salario Mínimo Mensual Legal Vigente. Ideal para empleadores, emprendedores y trabajadores que desean conocer el desglose exacto de los costos laborales y deducciones.

## 🚀 Características
- Cálculo de Base: Soporte para salario base y auxilio de transporte.

- Horas Extras y Recargos: Cálculo detallado de horas diurnas, nocturnas, dominicales y festivas según porcentajes de ley.

- Prestaciones Sociales: Provisión automática de cesantías, intereses sobre cesantías, primas y vacaciones.

- Seguridad Social y Parafiscales: Aportes del empleador a salud, pensión, ARL, SENA, ICBF y Cajas de Compensación.

- Historial Local: Guarda cálculos recientes directamente en el navegador utilizando localStorage.

- Diseño Responsivo: Interfaz moderna, accesible y adaptable a cualquier tamaño de pantalla.

## 🛠️ Tecnologías Utilizadas
- HTML5: Estructura semántica.

- CSS3: Diseño moderno, variables CSS, Flexbox y tipografía fluida.

- JavaScript Vanilla: Lógica de cálculos financieros, manipulación dinámica del DOM y almacenamiento local sin dependencias.

## 📂 Estructura del Proyecto
- `index.html` - Interfaz de usuario.

- `style.css` - Hoja de estilos.

- `script.js` - Motor de cálculos y eventos.
